# Agent instructions

## Agent skills

### Issue tracker

For issue and spec operations, use GitHub Issues in
`the-data-sherpa/my-first-software-factory`.
Read `docs/agents/issue-tracker.md` before tracker operations.

### Triage labels

Before triage or label changes, read `docs/agents/triage-labels.md`
and use its five-label mapping.

### Domain docs

Before code exploration or domain changes, read
`docs/agents/domain.md` for the single-context glossary and ADR rules.

### Change quality

Before implementing a change or reviewing a draft, read
`docs/agents/change-quality.md` for the shared quality standard.
Before reviewing changes or reporting verification coverage, also read
`docs/agents/review.md` for evidence, findings, and recheck rules.
